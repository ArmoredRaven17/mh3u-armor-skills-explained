## Game Data

The skill names, the in-game skill descriptions, the skill tree names and the skill tree ladders shown on the
page are read from the game's own text and data tables. The values in the detailed explanations were read by
the author from the game's code and data, extracted from a personally-owned copy. Only factual values and the
short in-game descriptions are reproduced; no game files are redistributed.

Community figures (Kiranico, the Monster Hunter wikis and community guides) were used only to cross-check
readings, not as a source.

## Icon

The talisman icon under [docs/assets/icons/](docs/assets/icons/) is the game's own talisman icon, cut from
its icon atlas and tinted with one of its rarity colours by the author's build script. It remains Capcom
property.

## Fonts and textures

typeface, and the menu textures under [docs/assets/](docs/assets/) are carried over from the sibling projects.
